WORKSHOP KREAFIS FURNITURE — LANDING PAGE
=========================================

Teknologi:
- HTML (di dalam index.php)
- CSS
- PHP
- JavaScript
- Tidak menggunakan database

CARA MENJALANKAN DI LARAGON:
1. Ekstrak folder workshop_kreafis_furniture ke C:\laragon\www\
2. Buka Laragon, lalu klik Start All.
3. Buka browser dan akses:
   http://localhost/workshop_kreafis_furniture/

CARA MENJALANKAN DI XAMPP:
1. Ekstrak folder ke C:\xampp\htdocs\
2. Jalankan Apache melalui XAMPP Control Panel.
3. Buka:
   http://localhost/workshop_kreafis_furniture/

PENTING — ATUR NOMOR WHATSAPP:
1. Buka index.php.
2. Cari baris:
   $whatsappNumber = '628XXXXXXXXXX';
3. Ganti 628XXXXXXXXXX dengan nomor WhatsApp workshop yang benar.
   Format nomor: kode negara + nomor, tanpa tanda +, spasi, atau angka 0 di depan.
   Contoh format: 6281234567890
4. Simpan file dan refresh browser.

CATATAN:
- Website ini tidak memakai database.
- Tombol konsultasi akan membuka WhatsApp dengan pesan otomatis setelah nomor diganti.
- Foto yang dipakai adalah foto referensi dari Unsplash dan membutuhkan koneksi internet.
- Ganti foto referensi dengan dokumentasi asli workshop jika tersedia, agar galeri menampilkan hasil pengerjaan yang benar.
- Informasi lokasi, kontak, harga, dan klaim layanan belum ditambahkan karena perlu dikonfirmasi pemilik workshop.
